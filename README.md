## **项目目标**

实现一个多人在线对战的“海战棋”游戏（实际上并非标准海战棋），支持：

* 账号登录与验证
* 创建 / 加入房间
* 房主发起开始游戏
* 游戏内实时通信（回合制战斗）
* 游戏状态同步
* 房间与玩家状态管理

---

## **Server 部分规划（Python asyncio）**

### **1. 基础结构**

* **网络通信**

  * 使用 `asyncio` TCP 服务器
  * 支持多客户端连接
  * 消息协议（JSON 格式）
  * 处理不同消息类型（登录、创建房间、加入房间、开始游戏、游戏操作等）

* **数据结构**

  * 在线用户列表（连接对象、用户名、状态）
  * 房间列表（房主、玩家、游戏状态）
  * 游戏数据（棋盘状态、回合信息等）

---
